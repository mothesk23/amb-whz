# AMB WHZ Zotero Citation Style

Zotero citation style for the AMB faculty at Westsächsische Hochschule Zwickau (WHZ).

## Installation
Download `amb-whz.csl` or install it directly in Zotero via:

Preferences → Cite → Styles → +

and paste:
https://raw.githubusercontent.com/mothesk23/amb-whz/main/amb-whz.csl
